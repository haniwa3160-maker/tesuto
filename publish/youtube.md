### タイトル案（上から推奨順）

1. `ここほれ、シロ！｜すてられたロボット犬と、50年まえのたね【はなさかじいさん 2026】`

### 説明文

```
灰色のコンクリートの中庭しかない団地に、ハナは引っ越してきました。
友だちはまだ、ひとりもいません。

そんなハナが粗大ごみ置き場で見つけたのは、
動かなくなった、白いロボット犬。

「ここほれ、ワン！」
シロが掘りあてたのは、小判ではなく――50年前に埋められた、ひとつぶの種でした。

でも本当のひみつは、シロが「掘っていた」ことではありませんでした。

日本の昔ばなし『はなさかじいさん』を、いまの子どもたちの毎日に置きかえた5分間のお話です。
「見返りを求めない優しさは、形を変えて返ってくる」
「本当にほしいものは、掘っても出てこない。埋めて、待って、育てるもの」
という、昔の人が伝えようとした芯はそのままにしました。
```

## 公開手順（このリポジトリからの流れ）

```bash
python3 src/build_audio.py       # ナレーション・BGM・SE → build/audio.wav, build/timeline.json
python3 src/build_video.py       # 本編   → out/kokohore_shiro.mp4
python3 src/build_video.py --shorts   # 縦型 → out/kokohore_shiro_shorts.mp4
python3 src/build_subs.py        # 字幕   → out/kokohore_shiro.ja.srt
python3 src/build_thumbnail.py   # サムネ → out/thumbnail.png
```

アップロード自体は YouTube Studio から手動で行ってください（このセッションには
YouTube アカウントの認証情報がないため、代理でのアップロードはできません）。
